# IMDB 影评情感分类
基于 **BiLSTM + 自注意力机制** 的电影评论二分类模型，实现正面/负面情感判断，验证集准确率达 **88.74%**。

## 项目简介
本项目针对IMDB电影评论数据集进行情感分类任务，在基础LSTM模型上引入多项优化策略，解决了长序列信息丢失、训练不稳定、过拟合等问题，最终在验证集上取得了88.74%的分类准确率。

## 核心特性
- ✅ **双向LSTM**：同时捕获前向和后向上下文语义
- ✅ **自注意力机制**：自动聚焦关键情感词，提升模型可解释性
- ✅ **LayerNorm归一化**：稳定训练过程，加速模型收敛
- ✅ **完整训练策略**：学习率调度、梯度裁剪、Dropout正则化、早停机制
